    客户如何拿到验证材料？

    使用你的中转站客户令牌，通过下方入口发送模型对应的原生流式请求，保存完整响应文件，再回到这里上传。GPT 和 Grok 走 Responses；Claude、Kimi 与已验证的火山模型走 Messages。

    Base URL: https://api.eonaibusiness.com/verified/response
Claude / Kimi / 火山模型：POST /v1/messages
GPT / Grok：POST /v1/responses
stream: true
显式输出上限：1–8192（Responses 可省略）

    先完成验证再返回响应，因此不会立即逐 token 输出。缺少证明、上游出错或核验失败时拒绝返回结果。Windows 请使用 curl.exe -o response.sse 保存原始字节。

    可信参考值与验证边界

    我们转交供应商生成的硬件证明，未自行运行该证明的 Nitro enclave。浏览器固定 AWS Nitro G1 根指纹和下列公开 PCR0，不接受上传文件自报的参考值。

    来源与响应验证可以确认官方端点及响应字节完整性；不能确认内部模型权重，也不能确认供应商未修改请求。证书过期会失败；相同请求之间的旧响应重放不由本协议完全解决。

    你可以下载开源版本，在自己的本机离线验证，无需信任本站提供的绿色提示。源码及版权来源保留在开源仓库的 NOTICE 和许可证中。
